# VIBE CODING | 프리미엄 MBTI 정밀 분석 프로그램

이 프로젝트는 사용자의 성격 유형(MBTI)을 정교한 알고리즘을 통해 분석하고, 시각적으로 매력적인 결과 리포트를 제공하는 웹 애플리케이션입니다.

## 주요 기능
- **프리미엄 UI/UX**: 글래스모피즘(Glassmorphism) 테마와 세련된 애니메이션 적용
- **정밀 분석 지표**: 4대 성격 지표(E-I, S-N, T-F, J-P)별 상세 백분율 그래프 제공
- **심층 콘텐츠**: 16가지 유형별 핵심 강점, 성격 요약, 추천 케미 정보 제공
- **사용자 편의성**: 답변 수정이 가능한 '이전 질문' 기능 및 모바일 최적화
- **공유 기능**: 결과 이미지 링크 복사 및 Web Share API를 통한 SNS 공유 지원

## 기술 스택
- HTML5 / CSS3 (Vanilla CSS)
- JavaScript (ES6+)
- [Font Awesome](https://fontawesome.com/) (아이콘)
- [Google Fonts](https://fonts.google.com/) (Typography)

## 개발 내역 (2026-06-07)
### 1. 디자인 시스템 전면 개편
- **프리미엄 UI**: 글래스모피즘(Glassmorphism) 스타일을 적용하여 투명도와 블러 효과가 어우러진 현대적인 디자인 구현
- **애니메이션**: 화면 전환 시 `slideUp` 애니메이션을 적용하여 생동감 있는 UX 제공
- **반응형 최적화**: 모바일과 데스크톱 환경 모두에서 최적의 가독성을 갖추도록 레이아웃 조정

### 2. 정밀 분석 기능 추가
- **성격 지표 시각화**: 4대 성격 지표(E-I, S-N, T-F, J-P)의 백분율을 실시간 계산하여 막대 그래프로 렌더링
- **상세 결과 리포트**: 16가지 유형별 '핵심 강점' 리스트업 및 심층 성격 해설 콘텐츠 보강
- **케미 매칭**: 최고의 궁합과 보완이 필요한 상성 정보 제공

### 3. 기능성 및 편의성 강화
- **이전 질문(Back) 기능**: 답변 기록(History)을 스택 구조로 관리하여 언제든 이전 답변을 수정할 수 있는 기능 구현
- **공유 자동화**: Web Share API 연동을 통해 스마트폰 기본 공유 창 호출 및 클립보드 복사 기능 탑재
- **로딩 애니메이션**: 데이터 분석 중임을 시각적으로 보여주는 펄스 애니메이션 적용
